# Objetivo del Proyecto: Luxe Estate

## Descripción
Crear una aplicación de venta de bienes raíces llamada **Luxe Estate**, usando **Next.js (App Router)** y **Tailwind CSS**.

Implementar el diseño y las funcionalidades básicas de una app inmobiliaria moderna, premium y minimalista.
